*comment pv_travel_dest comment), with pv_travel_dest already set by the
*comment caller. Computes the leg's cost as origin-distance + destination-
*comment distance (compound's own distance is 0, so a compound<->district
*comment leg collapses to just that district's distance for free), advances
*comment the clock, updates current_district, then hands off to the

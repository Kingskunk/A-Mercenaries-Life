*comment ladder, not division/modulo, to avoid any doubt about how this engine rounds negative division (never
*comment verified, and unnecessary when a plain *if chain says exactly the same thing with zero ambiguity).
*comment Covers the full legal 5e score range, 1-30. Thresholds are listed least-to-most-extreme in each
*comment direction, so the most extreme applicable one, being the last to run, is the one left standing.
*comment Output: sm_mod (number), sm_mod_str ("+4"/"-2"/... for display, same format the old hardcoded
*comment _mod_str strings already used).
*label score_to_mod
*params sm_score
*set sm_mod 0
*if (sm_score <= 9)
  *set sm_mod 0 - 1
*if (sm_score <= 7)
  *set sm_mod 0 - 2
*if (sm_score <= 5)
  *set sm_mod 0 - 3
*if (sm_score <= 3)
  *set sm_mod 0 - 4
*if (sm_score <= 1)
  *set sm_mod 0 - 5
*if (sm_score >= 12)
  *set sm_mod 1
*if (sm_score >= 14)
  *set sm_mod 2
*if (sm_score >= 16)
  *set sm_mod 3
*if (sm_score >= 18)
  *set sm_mod 4
*if (sm_score >= 20)
  *set sm_mod 5
*if (sm_score >= 22)
  *set sm_mod 6
*if (sm_score >= 24)
  *set sm_mod 7
*if (sm_score >= 26)
  *set sm_mod 8
*if (sm_score >= 28)
  *set sm_mod 9
*if (sm_score >= 30)
  *set sm_mod 10
*if (sm_mod >= 0)
  *set sm_mod_str ("+" & sm_mod)
*else
  *set sm_mod_str ("" & sm_mod)
*return

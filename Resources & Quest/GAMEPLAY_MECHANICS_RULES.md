# Gameplay Mechanics Rules

Shared implementation, combat, equipment, economy, UI, state-safety, and verification rules for *A Mercenary's Path*. Prose and voice live in `Resources & Quest/NARRATIVE_GUIDELINES.md`; quest design guidelines live in `Resources & Quest/QUEST_DESIGN_RULES.md`; step-by-step checklists live in `Resources & Quest/CONTENT_WORKFLOW.md`.

This file records current mechanics, variables, subroutines, and architectural constraints—not a changelog.

## 1. ChoiceScript Code Discipline & State Hygiene

* **Strict Line-Separated Flow Control:** `*if`/`*elseif`/`*else`/`*set`/`*goto`/`*gosub` must start on their own indented line, never inline in prose, or ChoiceScript prints raw code to the player.
* **No Nested Multireplaces:** `@{var1 @{var2 ...|...}|...}` fails to parse. Compute multi-condition hints into a `*temp` string before the `*choice` block.
* **Expressions Need Explicit Parentheses Around Every Operator Pair:** ChoiceScript does not chain operators (`a + b + c` fails). Nest pairwise: `(((gold * 100) + (silver * 10)) + copper)`, and write boolean chains as `(((a) or (b)) or (c))`.
* **Prose Formatting & Comments:**
  * A prose line must not start with `*` (parsed as a command). Mid-line, use `[i]…[/i]` instead of `*word*`.
  * `*comment` is the only comment syntax, and must not sit between an `*if` body and its `*elseif`/`*else`.
  * The engine drops a blank line immediately following an `*if` block that printed nothing. Place the blank line *before* an optional check, not after, and add a blank line directly under any `*label` reached by `*goto` so paragraphs break cleanly.
  * Never write dead text-only pages ending in a single `"Back…"` button (`*page_break`). Only keep a `*page_break` when the page holds something the player came to read or changes state before a shared label; otherwise print text, a blank line, and `*goto`. A shut-place page flowing into a hub must not carry its own `[b]◈ NAME[/b]` heading (two headings prevent banner sync).
* **Math & Negative Literals:**
  * `/` never floors (`10.5 / 14` prints verbatim). Always floor with `(X - (X modulo N)) / N`.
  * `*set var -1` is decrement shorthand, not assignment. Assign negative numbers with a parenthesized expression whose first token is not an operator: `*set var (0 - 1)`. Bare `*create` of a negative literal is invalid.
  * Bare `*create X 85` stores a string until arithmetic touches it; Node harnesses inspecting `stats` directly must coerce with `Number(v)`.
* **Variable Scope & Indirection Safety:**
  * `*temp` does not cross `*gosub_scene` boundaries; values shared across scenes must be `*create`d globals. A `*temp` used inside a scene entered via `*goto_scene <scene> <label>` must be declared *under* that entry label (lines above the first label are skipped on a label jump).
  * A `${var}` token inside a `*set` string resolves immediately at assignment time, not when printed (`*create` rejects `${}` defaults). Build dynamic lines inline after the referenced variables are set.
  * Quicktest walks every `*if` branch even when false, and compound `and`/`or` expressions do not short-circuit. Never construct dynamic variable names with `{}` from `character_class`, spell ids, levels, or any value that can be `"none"` unless every possible target exists—give excluded cases an inert placeholder (`slot 0`, `none`, `""`) or use explicit branches.
  * Never fire `*goto_scene` from inside an active `*gosub_scene`; surface an exit/death flag and let the top-level caller perform `*goto_scene` after returning.
* **Engine State Hygiene (`roll_d20_check`):** Temporary roll modifiers (`advantage`, `disadvantage`, `guidance_active`, `guidance_hold`, `check_silent`, `check_no_guidance`) reset inside `roll_d20_check` on return so they never leak across choices. Read `roll_had_advantage` if the caller needs to know whether advantage applied.
  * **Roll before advancing time:** In any option that both checks and spends time, roll first and call `advance_time` afterward so a 1-minute Guidance cast (`guidance_minutes_left`) is not spent before the roll. Where time *must* run first (long work shifts), set `guidance_hold true` before `advance_time` (`roll_d20_check` clears it on return). `roll_is_replay` keeps a sidebar Guidance cast intact across a dossier-close replay.
* **Refresh/Replay Safety (No Bare `*set var +N`/`-N`):** A browser refresh or Stats/Menu round-trip replays the current page from its start. Never use bare increments/decrements before a `*choice`, `*page_break`, or `*gosub`/`*gosub_scene`:
  1. **Prefer a derived stat** recomputed cleanly from persistent flags (`recalculate_armor_class`, `recalc_hp_from_neglect`, `Insignia.refresh`).
  2. **Otherwise, lock the mutation:** `*if (not(X_locked)) or (not(locked_X_page_id = page_id)) ... *set X_locked true *set locked_X_page_id page_id`. Reuse `currency_txn_locked` for currency and `stat_bump_locked`/`stat_bump2_locked` for one-off bumps. Never read a stat for display and reset it later on the same page outside the lock, and never combine a guarded mutation with an unconditional write to the same stat on the same page.
  3. **Capture pre-bump booleans inside the guard** if subsequent unguarded prose branches on the threshold that triggered the bump.
  4. **Multiple calls on one page:** A single `(page_id, call_id)` scalar only protects the *last* caller—loops calling a guarded routine 3+ times on one page need per-call-site boolean memory or a `*create`d `..._call_id` (never `*params`). Reset caller-supplied input variables (`minutes_to_pass`) unconditionally *outside* the lock.
  5. **One-time story grants** guard themselves directly with `*if (not(has_X)) ... *set has_X true` (or a dedicated `..._initialized` flag, never another stat whose `*create` default matches `"done"`).
  6. **Dossier replay & flow-keyed guards:** Because the dossier replays the game page underneath when closed, any dossier action calling `advance_time` (`codex_rest_short`, `codex_wait_now`) must save and restore `time_advance_locked`, `locked_time_advance_page_id`, `locked_time_advance_id`, and `time_advance_call_id` in `*temp`s. Inside the dossier, `page_id` is unreliable across sessions—key dossier replay guards on flow (`short_rest_applied`, cleared at `codex_rest`) or unique clock stamps (`last_short_rest_stamp`). Detect an open dossier with `window.stats.scene.secondaryMode === "stats"` (never `data-return`).
* **`startup.txt` Is Built From `web/mygame/scenes/startup_parts/`:** Edit the numbered part files (`NN_system.txt`, `40_gear_creates_generated.txt` via `gen_gear.js`, `99_game_settings.txt` last—no `*create` after the first choice) and rebuild with `node tools/build_startup.js`. `tools/lint_startup_parts.js` flags any direct edit to `startup.txt`.
* **Character Creation, Languages & Progression (`character_stats.txt`, `character_progression.txt`):**
  * Creation order: name, origin, race, class (`prologue/class_select.txt`), age, build, features, skin, camp night, dawn muster (`dawn_trial.txt` `trial_converge`), squad. Every class uses the same `16, 14, 12, 10, 10, 10` spread before racial modifiers (`class_done`); origins contribute narrative, coin, reputation, and flavour (e.g., Outlaw street-wise reads) rather than ability scores.
  * `apply_race_languages` derives `lang_<id>` on `update_dnd_stats` (Common + racial language; Humans and Hexbloods also store a chosen `lang_extra`; `known_comprehend_languages` stands in for missing languages).
  * `hp_max` (`character_level * (hit_die_max + con_mod)`) and `prof_bonus` (`2 + (((character_level - 1) - ((character_level - 1) modulo 4)) / 4)`) are computed only in `update_dnd_stats`.
  * **Class Resources & Rests:** Pool maxima (`Second Wind`, `Rage`, `pact_slots`, `spell_slots_1`/`_2`) live in `refresh_class_resource_maxs`. `restore_class_resources` (guarded by `rest_restore_locked`/`locked_rest_restore_page_id`) runs on a long rest via `resolve_sleep`. Short rests run via `short_rest_preview`/`do_short_rest`/`short_rest_banner` (`short_rests_max` = 2 between long rests via `short_rests_left`; Wizard/Bard/Ranger recover half their slots rounded up, Warlock recovers all, Second Wind recovers 1 use).
  * **The Level-Up Pool Is Derived From Success Flags:** `refresh_quests_finished` sums `count_finished_<name>` flags set once on successful quest completion (never cleared, never on failed endings or radiant jobs), and `refresh_level_up_progress` sets `level_up_ready`. If a quest sets its completion flag *after* `advance_time` has already run on the same page (with no `*choice` between them), call `*gosub_scene calendar update_hub_condition` immediately after flipping the flag so `quests_finished` stays accurate on refresh.
  * **Level-Up & Training:** `do_level_up` targets `level_up_from + 1`. Spell picks in `character_progression.txt` (`level_up_features`) are generated by `tools/gen_spell_book.js` (`MENUS` `maxLevel`, `learn_spell`, `prepare_auto_fill`). Training uses `training_preview`/`do_training_session` (sharing `last_training_day` once per day). Training locations show a hub button gated on `level_up_sessions_needed > 0`, keep the training option listed (reworded when unavailable), and pull vignettes from a rotating pool.
  * **Heroic Inspiration:** Every character has `heroic_inspiration` (`0` to `heroic_inspiration_max` = 4), awarded once per id via `*gosub_scene dice_engine heroic_award "short_id"` (`heroic_awarded`, `heroic_award_result`). Players arm it via `codex_heroic_arm`; `roll_d20_check` spends 1 point automatically on non-combat, non-silent DC checks (turning a straight roll into advantage, or cancelling disadvantage).
  * **Metadata Synchronization & Spell Slots:** New lore/location/faction/companion entries require `*create var false`, progressive disclosure in the dossier/lorebook, and matching dev-hub jump presets. When gating choices by spells/cantrips, check every slot so no build is excluded. Audit dossier ability-card descriptions against combat code before writing new abilities.

## 2. Equipment & Magic Item Systems

* **Catalog & Generation (`tools/gear_catalog.json` → `node tools/gen_gear.js`):** Tradeable items live in `tools/gear_catalog.json`. `gen_gear.js` (also run by `compile.js`; `--check` verifies freshness) rewrites `GEN:BEGIN`/`GEN:END` blocks in `startup_parts/40_gear_creates_generated.txt`, `equipment.txt`, `inventory-data.js`, `trade-data.generated.js`, `combat.txt`, and shop scenes. Never edit generated blocks by hand. Quest rewards and non-catalog story items stay outside the catalog.
* **Item Titles:** Keep item titles to 3 words or fewer, plain and unique (no treatment words like *boiled*, *oiled*, *waxed*, or lore prefixes—put those in `blurb` and dossier text). Item `id`s never change.
* **Stacking, Starting Kit & Paper-Doll Slots:**
  * `has_<id>` means "at least one"; `spare_<id>` counts extras. Modify inventory through `grant_gear` / `sell_gear`, never bare `*set has_<id>` on catalog items.
  * Starting armor and weapons are assigned by class in `dawn_trial.txt trial_converge` via `equipment.txt grant_class_armor` and `grant_class_weapons` (copying `starting_armor*`, `starting_cloak`, `starting_boots`, `starting_weapon*`).
  * Every paper-doll slot (`weapon`, `sidearm`, `head`, `cloak`, `hands`, `waist`, `feet`, `neck`, `ring1`, `ring2`, `shield`) uses `equipped_<slot>_id` and a pure `apply_<slot>_loadout` called from `update_dnd_stats`.
  * `equip_weapon` swaps rather than overwrites if the incoming id sits in `equipped_sidearm_id`. In combat, `[NO COST] [Swap Weapons]` calls `swap_active_sidearm` (replay-locked via `combat_swap_locked`/`locked_combat_swap_page_id`/`combat_swap_old_prose`).
  * `tools/gen_equipment_data.js` publishes `garment_traits` (`garment_hint`) to `window.GARMENT_HINTS` and item loadout tables to JS. `EquipmentEngine.recalcArmorClass` mirrors `recalculate_armor_class` and is verified by `node tools/check_ac_formula_sync.js`. `swappable: true` in `inventory-data.js` must match real slot capabilities.
* **Armor Tiers, Weapons & Bonuses:**
  * `armor_tier` derives from `armor_type` in `apply_armor_loadout` and `recalculate_armor_class`. Never gate gear visibility by class.
  * Catalog weapons carry `weapon_type`, `hands` (`"two_handed"` auto-drops shields), `reach` (`"medium"`/`"long"`), `ammo`, `magic: N` (+N to attack & damage), `magical: true`, `silvered: true`, `adamantine: true`, `flimsy: true` (-1 attack via `combat_apply_weapon_magic_attack`), and optional `fadesDays: N` (`magic_until_<id>`, expired by `expire_timed_weapon_magic` on hub entry and fight start).
  * **Ability-Score Bonuses vs. Roll Bonuses:** Ordinary equipment may grant `+1`/`+2` to an ability score via `garment_traits` (`recalculate_equipment_bonuses` takes only the single highest equipment bonus per stat; timed boons add separately). Bonuses directly on d20 rolls, attack rolls, or spell save DCs belong only to rare/named/late-game rewards.
  * **Attunement:** Magic items granting stat bonuses use `has_X`, `X_attuned`, `attune_item`/`unattune_item`, `max_attunement_slots`, and `base_<stat>` snapshots. Flavor items without stat bonuses skip attunement and equip directly via `equip_<slot>`.
* **Untrained Armor or a Shield Spoils Spellcasting:** `equipment.txt recalculate_proficiency` sets `armor_nonprof`, `shield_nonprof`, `spells_blocked`, and `spells_blocked_why` (blocking Wizards in any armor/shield, Bards/Warlocks in medium/heavy armor or shields, Rangers in heavy armor), then calls `character_progression refresh_known_spells`, which gates `known_<spell>` on `not(spells_blocked)`. All story gates, fight spell options, and invocations respect `spells_blocked`, while items (spell scrolls and `item_cantrip` / Moonshard's `known_light`) are unaffected. `equipment-panel.js recalcProficiency` / `EQ.refreshKnown` mirrors this in JS.
* **Consumables, Food & Special Catalog Mechanics:**
  * Consumables (`kind: "consumable"`) resolve exclusively through `use_consumable` (and dossier one-shot `codex_use_now`), never ad-hoc `*set has_x false` blocks.
  * **Temporary HP never stacks:** Every source (food, False Life, Armor of Agathys, Fortifying Tonic, Heroism Potion) sets `temp_hp` to `max(temp_hp, new_value)`.
  * **Food & Auto-Eat:** Foods use `effect: { type: "ration", food: <minutes> }`. Manual eating is refused within 6 hours of the last meal; on the road or in a dungeon (`calendar.txt advance_time`), when `minutes_since_meal` hits 2160 (36h Starving), the engine automatically consumes the largest eligible food (`food_pick`, skipping `autoEat: false` or unmet `autoEatAfter: "<flag>"` quest ingredients) and records consumption in `food_cnt_<n>` / `food_eaten_note`.
  * **Combat Potions, Scrolls & Class Tools:**
    * Potions tagged `"combat": "potions"` populate `combat_potion_options` (`Potions: <Title>`, 1 Action); out-of-combat instant heals share `last_mundane_treatment_day`.
    * **Spell Scrolls** (`effect.type: "scroll"`, `effect.spell`) create `has_scroll_<spell_id>` and let anyone cast (`combat_scroll_id` in combat; `outOfCombat` buffs from the Pack). Non-casters use INT (Fighter/Rogue) or CHA (Barbarian) via `spell_save_dc`/`spell_damage_mod`.
    * **Special Arrows** (`fire_arrow`, `ice_arrow`; `effect.type: "arrow"`) populate `combat_arrow_options` for weapons with `weapon_ammo: "arrow"`, applying a separate elemental damage packet (`combat_arrow_apply` / `combat_arrow_kind`). Plain arrows stay unlimited.
    * **Camp Kit (`camp_kit`):** Tracks `camp_kit_wear` (`camp_kit_state`: New < 8, Worn 8–15, Ragged 16–23, spent at 24 -> falls back to `spare_camp_kit`), updated on camp sleep via `camp_kit_wear_night` (1 clear / 2 rain / 3 storm) and repaired with `camp_kit_mend` (`check_task_type "repair"`). Reduces wet exposure while `exposure_camping` is set.
    * **Water Jug (`water_jug`):** Tracks `jug_full` (`holds: { var: "jug_full", extra: 7 }` adds 7 lb per full jug; `jug_trim` keeps `jug_full <= owned` on sales; stowing/selling moves empty jugs first via `stow_<container>_jug_full`). Filled via `jug_fill` where `water_at_hand` is true; thrown in combat (`fight_throw_water`) to make the foe Wet for 2 turns (see Wet under Conditions; burning foes are immune).
    * **Poisoner's Robes & Bramble Heart:** `poisoners_robes` adds `+1d4` poison to player spells via `combat_dice.txt apply_poison_rider`. `bramble_heart` (`ACTION`, once per day via `bramble_heart_day`) calls `fight_summon_blights` to seat 1d2 `blight_twig` allies (`combat_summon_locked`).
* **Weight, Load & Containers (`inventory.js`, `calendar.txt calc_load`):**
  * Every item has `weight` in 0.05 lb steps (`tools/check_inventory_weights.js`); coins weigh `0.02` lb each; starting gear uses `starting_weights`. Carrying capacity is `15 * STR` (`loadOf`).
  * Over capacity adds `load_over_pct` (1% per excess pound, rounded up, capped at +50%) to `load_extra_mins` on overworld and dungeon steps, advancing `minutes_since_rest` faster without affecting hunger or the clock. Shops warn on purchases that exceed capacity via `InventoryPanel.overloadNote` (`gear_warning_text`).
  * **Containers:** Defined in `tools/gear_catalog.json` `containers` (with `capacity`, `needs`, `needs_reason`, `dungeon: "waits"`, and optional `rider: true` subtracting `body_weights` by race). Generated `stow_<container>_<item>` stats hold stowed units outside the player's load and gear checks (`stowUnits`/`takeUnits`, disabled in combat).

## 3. Reusable Town-Content Primitives & Dynamic Economy (`economy.txt`, `market.js`, `world.js`)

* **Shared Economy Subroutines (`*gosub_scene economy <label>`):**
  * `currency_add` — signed copper-equivalent arithmetic via `currency_add_amount` against `gold`/`silver`/`copper` (call inside caller's `currency_txn_locked`). Never subtract gold/silver/copper columns independently; always convert via total value.
  * `resolve_wager` — self-locked gambling helper reading `wager_bankroll_var`, `wager_ante_copper`, `wager_win_copper`, and `check_*`; returns `check_success` and `wager_bankroll_busted`.
  * `buy_tavern_item` — self-locked tavern purchase handling coin, healing, and nourishment boons.
  * `apply_unique_buff` — applies timed ability-score boons or negative afflictions (`buff_<stat>_bonus` summed by `recalculate_buff_stats`). Never mutate base stats directly after chargen or add buffs directly to d20 rolls—boons raise ability scores so modifiers step on even numbers.
* **Buyer Bonuses & Counted-Salvage Buyers:**
  * `sell_bonus_percent` (`equipment.txt`) computes `sell_bonus_pct` (+5% per positive `cha_mod`), applied last in `gear_unit_value` rounded nearest half-up, and read by `trade.js`.
  * Counted salvage buyers (`herbalist` via `herbalistPiece` and `gear_piece_herbalist`; `game` via `gamePiece`) buy whole stacks at per-piece rates; `trade.js unitPrice` mirrors `equipment.txt`.
* **Dynamic Markets (`web/mygame/market.js`, `tools/market_defs.json`, `tools/gen_markets.js`):**
  * Dynamic merchants store serialized shelf/purse/appetite state in `stats.market_<key>` (`startup_parts/48_market.txt`) and open `trade.js` as a layer over ChoiceScript settle labels (`market_cost`, `market_credit`, `market_on`). Fixed/unique items (`fixed`) keep flat prices and never restock; `menu: false` shops hide fallback menus.
  * **Price curve:** `unitPrice = base * worldLevel * stockFactor`, clamped between `MIN_ASK` (`0.5x`) and `MAX_ASK` (`2x`). Stock factor stays flat (`1.0`) from `0.5x` to `1.5x` target stock, climbs to `2.0` on an empty shelf, and drops toward `0.25` when flooded. Buyback (`bid`) pays `buyPct` (`<= 0.8`) of the asking price *after* the unit arrives, scaled by `commodity.need`. Player-sold goods stay reserved on the shelf for 14 days. Commodity markets cap daily spend per good at `appetite.stocked` (10% of purse) or `3%` for unstocked goods (`spentToday`).
  * **Shared Commodity Cart (`shop_cart_run`):** Open markets (`commodities: true`) generate a single `*gosub_scene equipment shop_cart_run <buyer> <sell_key> <buy_key>` cart pass walking `cart_buy_ids`/`cart_sell_ids` (`|id|...|`), and `genPanelRows` skips per-item `shop_row_add` except for armor, shields, or `warn` items.
  * **Trade Book & UI (`trade.js`, `tradebook.js`):** Tracks weighted average cost paid (`stats.trade_basis`), cumulative profit (`stats.trade_profit`), and prices from up to 6 markets (`stats.trade_seen`: 3 newest visited + 3 newest heard via rumor). Rows show live unit ladders (`Market.ladder`), `#csTip` hover cards, left-rail search/sort/group folds, Shift-click (`±10`), Ctrl/Cmd+`+` (max affordable), and Ctrl/Cmd+`−` (clear).
  * **Market Rumors (`market_rumor_check`):** Fires silently once per day per open market (`rumor_log`, `rumor_page_id`, `check_silent`, `check_no_guidance`) using best of Perception/Investigation/Persuasion vs tier DC (village 10, town 12, city 14). Success adds or refreshes the nearest unrecorded open market in `stats.trade_seen` (age 0–3 days by margin; natural 20 teaches 2) and prints an anonymous world-event or price-swing tidbit.
* **World Supply Simulation (`web/mygame/world.js`, `tools/gen_world.js`, `world_seed`):**
  * Commodities carry `commodity` metadata (`makers` with `major`/`minor`, `reach` miles, `need`, `store` EMA time constant in days, `season` curve, `inputs` dependency shares, `tradeGroup`).
  * `tools/market_defs.json` holds settlement `population`, per-capita `demand`, `industry`, `dseason`, and `events` tables. Makers serve their own settlement first, then distribute surplus to markets within `reach` weighted by distance and population pull, smoothed through `store` stockpiles and input chains (`iron_ore`→`iron_bar`→smiths, `wool`→`cloth`, `raw_hide`→`leather`), plus scheduled 30–90 day anonymous regional/local events (`World.eventsAt`, checked by `tools/check_market_loops.js`).
* **Recipes:**
  * **Adding a trade good:** Add `commodity` (`makers`, `reach`, `need`, `store`, `tradeGroup`, etc.) and `retail` in `tools/gear_catalog.json`, then run `node tools/gen_gear.js`, `node tools/gen_markets.js`, `node compile.js`, and `node tools/gen_gear.js` again.
  * **Adding a settlement market:** Add a `trades` entry (`commodities: true`, `menu: false` buy/sell shops) in `tools/gear_catalog.json`, create a scene with the panel and settle labels (copy `timbermouth/market.txt`), add its entry (`tile`, `purse`, `depthMult`) in `tools/market_defs.json`, register its key in `PILOT` in `web/mygame/trade.js`, and add `*create market_<key> ""` in `startup_parts/48_market.txt`.
  * **To add a merchant:** Add its key to `PILOT` in `web/mygame/trade.js`, set `menu: false` on its shops in `tools/gear_catalog.json`, remove hand-written menu rows/labels from the scene, and run `node tools/gen_markets.js`.

## 4. Testing Tools & Verification

* **Structural & Fuzz Harnesses:**
  * `node quicktest.js web/mygame` (or `node tools/quicktest_parallel.js --changed`, or `node tools/quicktest_scene.js <scene>` for seconds-fast single-scene runs): parses and walks every reachable line.
  * `node randomtest.js num=N seed=S` (`showUnreachedLabels=true`, `showDeadSpace=true`, `gotoLoopCap=N`): random playthroughs (`OPEN-WORLD WANDER` marks infinite-loop-free exits).
  * `node refresh_fuzz_test.js num=N seed=S mode=smart archetype=str|dex|con|int|wis|cha|balanced`: detects `[refresh-duplication]` bugs by snapshotting and replaying every pause. Note: ignore `[shadow-diverged]`/`[shadow-no-pause]` at `*gosub_scene` pause points (no `choice_subscene_stack` reconstruction); test cold refresh there directly.
* **`tools/scripted_play.js` & `tools/play_all.js`:**
  * Plays deterministic JSON scripts in `tools/play_scripts/` (`refresh: true`, `refreshText: true`, `seed`, `rand`, `sabotage`, `replaySet`, `optional: true`). A script can carry `expect` (`vars`, `text`, `noText`, `status`) so it fails by itself when the rule it shows breaks; give new scripts one (the header of `tools/scripted_play.js` has the fields).
  * **Dead space fails by default:** Any `*line_break` printing an empty line fails unless `"allowDeadSpace": true` is explicitly marked (no script carries it). The transcript names the scene and line ("!! DEAD SPACE", counted from 0). Usual causes: a `*line_break` straight after a routine that already ends its paragraph (a dice banner, `fight_victory`, `fight_cured`, a time skip); a page that passes time (`calendar.txt`'s blank lines end the caller's paragraph) and then prints a `*line_break`. Pass the time before the page's prose instead.
  * **The `weather` shortcut pins the whole day** (`weather_day`, `weather_day_wet`) so `update_hub_condition` preserves forced weather across entries.
  * Always test a fight through its real caller scene, never a bare jump into `combat.txt` (which lacks a `*return` frame).
  * **A library fight's opening page is not refresh-checked (2026-11-22):** a script starting at `combat:fight_library` stands in for a story scene that sets the fight's inputs (`combat_enemy_hp_override`, `combat_enemy_advantage`...) and calls the fight on the same page. In the game that page starts in the caller, so it is never resumed inside combat; in the harness the inputs are starting stats already spent, so a replay would build a different fight. The tool skips that one page (counted as skipped) and checks every later one, so library fights run with `"refresh": true` like any other script.
  * **In a `seed` fight, refresh on or off changes the later rolls** (the replay re-seeds the page guard's dice globals and the tool does not put them back). Both streams are fair, and the seeded refresh scripts are tuned on this one, so turn refresh on or off before tuning a seed, not after.
  * **Speed (2026-11-22):** `scripted_play.js` swaps the engine's slow `crc32` for a table-based one with the same result (`tools/check_fast_crc.js` proves it on every scene; `FAST_CRC_OFF=1` turns it off) and keeps V8's compiled code for the engine scripts in `<system temp>/cs_scripted_play_vm_cache`, keyed by each file's text (`VM_CACHE_OFF=1` turns it off). The full suite went from about 537 s to 404 s.

## 5. Reusable Small-Combat Engine (`dice_engine.txt` / `combat_dice.txt` + `resolve_*`)

* **Attack & Skill Checks (`dice_engine.txt`):**
  * Player weapon/spell attacks use `roll_d20_check` with `check_dc = combat_enemy_ac` and `check_add_prof_bonus true`. Save-based spells use `resolve_save` against `spell_save_dc`.
  * Multi-skill checks use `*gosub_scene dice_engine roll_skill_check <DC> "<s1>" "<ovr1>" "<s2>" "<ovr2>" "<s3>" "<ovr3>"` (always 7 args, `""` for unused; ability overrides force a stat while keeping the skill's proficiency/label; supports Expertise). Set `check_task_type "repair"` (for Investigation/Sleight of Hand Repair Kit +1) or `check_gear_context "leverage_repair"` (Investigation Repair Kit +1, Athletics Iron Prybar advantage—only if that skill wins, reported in `check_skill_id`).
  * Skill proficiencies stack inside `update_dnd_stats` (`apply_background_skills`, `apply_class_skills`, `apply_race_skills`).
* **Hit, Attack & Initiative Primitives (`combat_dice.txt`):**
  * `resolve_player_hit` / `resolve_player_weapon_hit` — apply damage to `combat_enemy_hp` (floored at 0, self-locked; weapon variant resolves Sneak Attack and Hex/Hunter's Mark riders only on attack-roll hits).
  * **The player's weapon die** is the weapon's own, read from `weapon_damage` ("1d6 piercing", set per weapon in `equipment.txt`) by `weapon_die_sides` (combat_dice.txt), and shown the same way on the fight HUD's weapon card (`battlehud.js weaponStats`). Never from its category. A weapon with no die ("1 bludgeoning", bare hands) deals a flat 1, which a critical hit does not double. Every weapon is one die today; a two-dice weapon (a greatsword's 2d6) needs the roll to take a die count first.
  * `resolve_enemy_attack` — resolves either an attack roll against `armor_class` (+5 Dodge/Shield/+2 Cover/Reckless) or a save attack when `combat_enemy_atk_save_stat` is non-empty (calls `resolve_save` on `"combat_player_"` via `collect_save_modifiers`, skips AC/Shield/Dodge/Cover/Reckless/close-range penalty, halves on pass when `save_half` is true). Reads per-slot `_advantage`/`_disadvantage` (cancelled when both true).
  * `combat_roll_initiative` (in `fight_setup`) shares `combat_init_locked`/`locked_combat_init_page_id` with `apply_ability_score_range`, `apply_derived_combat_bonuses`, and setup `*rand` picks.
  * Weapon targeted-attack callers (`resolve_weapon_attack_choice` and `equip_weapon` sidearm-swap) keep `combat_atk_choice_locked` / `locked_combat_atk_choice_page_id`; in-fight spells rely on `pageReplayGuard` + `combat_chain_begin`/`combat_chain_end` and write **no** spell-layer replay locks.
* **Reactions & Duration Spells:**
  * Reaction spells (`Shield`, `Hellish Rebuke`) arm via persistent flags (`shield_armed`, `hellish_rebuke_armed`) from the hub at no cost and trigger inside `resolve_enemy_attack`, spending a slot and `player_oa_used` (`combat_rebuke_*` buffers output).
  * Out-of-combat hour-long spells (`Mage Armor` 24h, `False Life` 12h) track `mage_armor_minutes_left`/`false_life_minutes_left` (ticked by `advance_time`), use `*_cast_check` + locked `cast_*` routines, and share `codex_cast_now_<spell>` + `CASTABLE_OUT_OF_COMBAT` (`index.html`). Free invocations (`Armor of Shadows`, `Fiendish Vigor`) call the same routine with cost `"free"`.
  * `temp_hp` is tracked separately from `hp_current` and absorbed first on hits.
  * Bonus-action spells return free to `fight_round_hub`; full-action spells, Second Wind, and Rage consume the round.
  * Attack cantrips each get their own `*choice` option (never one generic option behind an `*else` chain). Unusually shaped spells (automatic hits, no roll) stay inline rather than distorting shared primitives.
  * Combat hit/miss pools need 3+ physically distinct phrasings; killing blows use generic damage-type finishers checked immediately after every damage source.

## 6. Combat as a Standalone Scene File (`combat.txt`) — Fight Library Pattern

* **Core Structure (`combat.txt`, `combat_prose.txt`, `combat_types.txt`, `combat_ai.txt`, `combat_spells.txt`):**
  * Call a fight with `*gosub_scene combat fight_<name>` (library scenes are listed in `compile.js` `verifyFileName(...)`, never `*scene_list`). Returns `combat_outcome` (`"victory"`, `"rescued"`, `"fled"`, `"cured"`, `"player_died"`).
  * `combat_engaged` stays `true` from `fight_setup` until `fight_cleanup` (Pack Use/open blocked while `true`).
  * `combat_player_can_die` defaults `false` (floors `hp_current` at 1); set `true` for lethal fights and always handle `"player_died"` at every fight call site. Set `combat_no_flee true` to hide `"Break off and run"`; set `combat_leader_slot N` to end the fight immediately when slot N drops to 0 HP; set `combat_nonlethal_slot N` to make only slot N yield non-lethally (also sets `combat_player_creature` from each attacked slot's library type).
  * `fight_setup` clears stale `_hp`/`_max_hp` on unused enemy/ally slots above `combat_enemy_count`/`combat_ally_count`. Reset per-fight/condition/movepool flags in `fight_cleanup` (never `fight_setup`, which runs after the caller sets overrides).
* **Enemy & Ally Slots (`combat_enemy1..6_*`, `combat_ally1..4_*`):**
  * Slot 1 mirrors bare `combat_enemy_*` scratch via `fight_sync_target_in`/`_out` around single-target primitives. **Checklist:** every new field set by a slot-1 `apply_type_*` branch must also be copied in `fight_setup`'s slot-1 snapshot.
  * Operations over slots use `{}` name indirection (`*temp p (("combat_enemy" & slot) & "_")`) with inert `0` placeholders for Quicktest.
  * `apply_enemy_type` (`combat_lib_N`) / `apply_ally_type` (`combat_ally_lib_N`) populate generic weapon/creature archetypes (`swordsman`, `archer`, `beast`, `zombie`, `hedge_mage`, `twig_blight`, etc.). Override with `hp`/`ac`/`atk`/`dmg_sides`/`dmg_type`/`size`/`nonmagic`/`immune`/`resist`/`vulnerable` overrides (sentinels `999` or `0` for ability scores), or pass `""` for `combat_lib_N` to inject custom/pre-wounded stats directly.
  * **Unique allies** (named people) are ally library types too, with fixed scores (min = max in `apply_ability_score_range`): a quest sets `combat_ally_lib_N` to the id and nothing else, no name or epithet overrides. `lyra` (`apply_allytype_lyra`, `combat_types.txt`): a level 2 rogue, 17 HP, AC 14, recurve bow as a shortbow +5 (1d6+3), dagger sidearm (1d4+3), steady morale, the sharpshooter profile, Sneak Attack 1d6.
  * **Ally Sneak Attack** (`resolve_ally_attack`, `combat_dice.txt`): an ally type sets `combat_allyN_sneak_dice` (`apply_ally_type` zeroes it for every slot first; give it only to a type whose weapons are all ranged or finesse). On a hit with advantage, or with no disadvantage while the player is Engaged with the target (its range 0) or another living ally is at range 0, it adds that many d6, doubled on a critical, inside the weapon's damage packet; the damage banner shows ` +N (Sneak Attack)`. No once-per-turn tracking: an ally attacks once on its own turn and an opportunity attack falls on another's turn.
  * **Target scoring's opening factor** (`combat_score_opening`, `combat_ai.txt`; the factor list is `combat_score_targets`' header): 10 when an attack on the candidate would have advantage, for every fighter (an enemy target through `combat_attack_edge`; the player or an ally when blinded, restrained, paralyzed, off-guard, off-balance, or prone on the attacker's tile), plus 10 for an ally with `sneak_dice` when `ally_sneak_beside` (`combat_dice.txt`, shared with `resolve_ally_attack`) says someone of its side is beside the candidate. Weight `combat_behavior_tw_opening` 2 for every profile (`resolve_behavior_profile`). It reads conditions only and never spends Off-Guard.
  * **AI hazards** (2026-11-21, `combat_score_terrain_destination`, `combat_ai.txt`): every Web (the player's `web`, an enemy's `foe_web`, an ally's `ally_web`) and every Grease patch scores -3 for every profile, so an optional step never enters one and a fighter standing in one steps off (banner "Steps Clear of the Web" / "Steps Off the Grease", step reasons `leave_web` / `leave_grease`). The wait-at-the-edge rule (`combat_ai_web_balk`) reads `combat_any_web_at` (`combat_movement.txt`), so it covers every web too. A ranged actor prefers the away step on a tie, and keeps a step off a hazard even where no tile is out of melee reach, as long as it is no more exposed than staying. Allies have no web balk: the only allies that walk toward a foe are melee guardians, which push through webs as enemy guardians do. Required moves (closing, chasing, retreating) still go straight, hazards or not.
  * **Assigned abilities (`tools/ability_book.json` -> `node tools/gen_abilities.js` -> `ability_facts_load`, `combat_abilities.txt`):** the non-magical twin of assigned spells. Each enemy slot has `ability_1..3` and `ability_uses_1..3`, filled by `combat_enemy_ability_K_override` (slot 1) / `combat_enemyN_ability_K_override`; a type names defaults (its special move in slot 3), a fight's override wins per slot, and `"none"` clears one. Kinds: `attack_variant` (a special move, loaded into the slot's `move2_*` fields by `ability_refresh_variant`), `action` (the Net: `ability_pick_action` / `ability_use_action`, asked before an assigned spell), `extra_attack`, `on_hit_rider` (a damage packet or a stun, loaded by `ability_refresh_rider`) and `trait` (`ability_has_trait`). Turn order: an action ability, then an assigned spell, then a plain attack, each with its own chance and worth-it rule. Uses are per fight, recharge 5-6, or a plain chance. Every pick is locked per slot per page.
  * An enemy holding an `extra_attack` ability (`combat_enemy_ability_K_override`, catalog `tools/ability_book.json`, the assigned-abilities rule above) attacks again after its attack on the player, each on its own `*page_break` page (since `resolve_enemy_attack` locks per slot per page): `multiattack` with its own weapon, `offhand_knife` with a d4 piercing knife (Captain Trent). A type's special move (a secondary attack carrying its own condition flag) is an assigned `attack_variant` ability (catalog `tools/ability_book.json`, the type's default in ability slot 3 via `ability_type_default`); `ability_refresh_variant` loads it into the slot's `move2_*` fields, and `combat_enemy_move2_chance` (0–100) gates it each attack. Never write `move2_*` on a type by hand.
  * Undead Fortitude (the `undead_fortitude` trait, the zombie type's default ability; any enemy holding it, checked by `combat_abilities.txt ability_has_trait`): dropping to 0 HP triggers `fight_undead_fortitude_roll` (CON save DC `5 + damage`, staying at 1 HP on pass), bypassed by radiant damage or a natural 20 (`combat_hit_nat20`).
  * **Ally slots & interception:** `allyDistanceToPlayer` (`index.html`) computes `abs(distance(player, target) - distance(ally, target))`. `find_intercepting_ally` lets a range-0 ally draw melee attacks via `resolve_enemy_attack_on_ally`; allies support `resist_types`/`vulnerable_types`/`immune_types` and take no secondary conditions.
* **Shared Lane, Positioning & AI (`combat_movement.txt`, `combat_ai.txt`):**
  * **Morale advantage (`combat_morale_check`, 2026-11-22):** a morale save has advantage when the checker's side is winning, judged by the two sides whole: the share of HP left on the player's side (the player and every ally; a downed ally adds 0) against the enemy side's (every enemy on the field; fled or surrendered add 0; a reinforcement still on its way is not counted). The larger share is winning. `tools/test_morale.js` covers it.
  * **Reinforcements:** a slot with `combat_enemyN_arrives` above 1 waits off the field (`combat_reinforcements_hold`: `_out` "reserve", HP kept in `_reserve_hp`) and arrives as its round turns over (`combat_reinforcements_arrive`), or at once if the rest of its side falls. It enters at its own edge of the lane unless `combat_enemyN_enters_at` (default 99) gives a range tier from the player (0 Engaged up to `combat_max_range`, on its own side; an encounter template's `enters_at`, which needs `arrives`); Engaged and Close entries get their own arrival lines.
  * Combatants track absolute lane coordinates (`combat_lane_player_position`, `combat_enemyN_position`, `combat_allyN_position`) and side (`combat_enemyN_side`: `1` ahead, `-1` behind). `effectiveRange(s, kind, slot)` and `combatantSubLine` (`index.html`) handle chase vs. lane distance displays.
  * **Targeting & AI:** `fight_pick_target` defaults to lowest-HP living enemy unless overridden by sticky HUD click `combat_player_chosen_target`. `choose_melee_enemy_target` and melee `select_ally_attack_target` pick nearest opponent (tiebreak: lowest HP fraction, then lowest HP); `choose_ranged_enemy_target` and ranged `select_ally_attack_target` pick most wounded opponent in reach (excluding hidden players).
  * **Behavior profiles (`resolve_behavior_profile`):** `bruiser`, `skirmisher`, `sharpshooter`, `guardian`, `feral`, `caster` (`combat_behavior_kite_to_edge`, `combat_behavior_oa_weight`). Cornered `caster` profiles run `combat_cornered_decide` to weigh disengaging (if an OA is lethal), retreating and shooting, or drawing `sidearm_*` (`fight_enemy_quickdraw` swaps scratch only and clears `move2_chance`). A profile that avoids melee threats and stands out of every melee foe's reach never takes a terrain step (cover, high ground) into such reach (`combat_choose_ranged_tactical_step`).
  * **Movement & OAs:** `combat_player_moves_left`/`_max` funds `Push Forward` / `Fall Back` (1 tier via `combat_shift_all_ranges`, targeted via `fight_pick_nearest_target`; read-only previews never mutate state). `Push Forward` past an engaged enemy (`combat_engaged_slot`, `combat_pushpast_locked`) leaves them behind (`side = -1`) and provokes one melee OA unless `Disengage` is active. `Dash` grants +1 move. `find_opportunity_attacker` allows at most one OA per move and one per enemy per round (`combat_enemyN_oa_used`), captured *before* distance opens; reverse OAs sync both scratch and slot (`fight_sync_target_out` / `_in`).
  * **Reach & Ranged Penalty:** Weapons and spells use four reach classes (`touch` 0, `short` 1, `medium` 2 [3 in 6-band], `long` any; `spell_reach_ok_<id>`), re-checked on option click (`fight_reach_check_at`, `fight_retarget_to_range`). Ranged attacks while any living foe shares your tile (`combat_any_engaged` / `combat_ranged_cornered`) suffer disadvantage (except Close Combat Shooter weapon shots and touch spells). A paralyzed foe is incapacitated and spoils no shot: `combat_check_engaged` skips it, and the spell and weapon penalties read only that scan, so a new condition that incapacitates is added there once.
  * **Shove, Hide & Dodge:** `Shove` (Athletics vs `10 + max(STR, DEX) mod`, target at most one size larger) pushes 1 tier without provoking OAs (`combat_shove_locked`). `Hide` uses `combat_hide_dc_calc` (`10 + highest enemy WIS mod - 2 if nearest at Long Range + 2 * combat_hide_uses`, min 8) and enforces a 1-turn cooldown (`combat_hide_free_round`). `Dodge` grants `+5 AC` via `dodge_active` and sets `combat_can_move false`.
  * **Steady Aim** (rogue level 3, `feature_steady_aim`, a class feature): the bonus action `Steady Aim` (`combat_can_steady_aim`: a bonus action, an attack left, not already armed, and no move this round; `fight_move_spent` sets `combat_player_moved_round`) sets `combat_steady_armed` and `combat_steady_round`. `combat_hidden_attack_roll` spends it for advantage on the next attack roll, hit or miss; `fight_end_player_turn` drops an unspent one. While `combat_steady_round` is this round the hub zeroes the moves (beside Pinned), hides Dash and shows `[🎯 Holding your ground: no movement this turn]`. Battle bar icon `Weapon_action/Brace_Ranged_Icon.webp`.
* **Conditions, Riders & Concentration:**
  * **Unified conditions (`combat_dice.txt`):** `condition_apply prefix name rounds dc src`, `condition_has`, `condition_end`, `condition_end_by_source name src` and `condition_tick` (ticked at player, enemy and ally turn end) address `"combat_player_"`, `"combat_enemyN_"` and `"combat_allyN_"`. Each condition is three fields: `<prefix><cond>` (rounds left, 0 = none), `_dc` (its repeat-save or escape DC) and `_src` (caster prefix & spell id, `""` for none). A concentration spell ends only its own copies with `condition_end_by_source` in its `concentration_end` branch, and `concentration_reconcile` ends the spell once nothing it caused is left. Shared now: Blinded, Slowed, Frightened, Restrained, Paralyzed. `Blinded` imposes disadvantage on attacks and grants advantage to attackers; a Blinded player loses `combat_player_can_see` (blocking sight-targeted spells and Hellish Rebuke triggers).
  * **Adding a condition:** (1) create the three fields for `combat_enemy0..6_`, `combat_ally0..4_` and `combat_player_` in `startup_parts/31_combat_engine_state.txt`; (2) reset them in `fight_setup`'s stale-slot loops and in `fight_cleanup`; (3) tick it in `condition_tick`, opening the slot's save lock (`combat_save_locked_<lock>`) before a repeat save, because another save may have used it earlier on the page; (4) wire its effect at the narrowest shared routine (`combat_attack_edge`, `combat_can_react`, `resolve_save`, the turn gate in `combat_next_turn`); (5) show it on the tracker (`index.html` `CONDITION_KEYS` and `STATUS_GLYPHS`). Inside `concentration_end`, keep the caster prefix in a temp before calling `condition_end_by_source`: `condition_end` takes `ce_prefix` as its own parameter and overwrites it.
  * **Other enemy conditions:** `Slowed` (no Dash), `Frightened` (disadvantage, repeat save), `Stunned` (`combat_stun_gate` skips turn, attackers gain advantage via `combat_attack_edge`), `Greased` (the grease flask, one target: `_greased`, `combat_grease_gate` DC 10 DEX check on move or fall Prone; a greased foe, or one standing on a Grease patch, takes fire attacks with advantage via `combat_attack_tag "fire"`), `Burning` (`combat_burn_tick` 1d4 fire +1 if greased; non-feral foes spend action to douse 2/3 of the time), `Restrained` (from Ensnaring Strike or Web, told apart by `_src`; at the start of its turn `combat_restrain_tick` deals Ensnaring's 1d6 piercing thorns, none for Web, then a foe that wants to move spends the turn on a Strength check against the stored DC and one that does not attacks from the spot with disadvantage; attacks against it have advantage; its Dexterity saves have disadvantage (`resolve_save`, banner "(disadvantage, Restrained)"); it ends when torn free or when the spell's concentration ends; fire on an enemy in a Web patch burns the web away, one shared 2d4 fire to each enemy on it, and ends the Web, `web_burn_check`), `Paralyzed` (Hold Person: loses its turns at the stun gate, no reactions, attacks against it have advantage, fails Strength and Dexterity saves without a roll, does not flee from Dissonant Whispers, repeats its Wisdom save at the end of each turn; works the same on the player and allies; a hit on it by an attacker Engaged with it is a critical hit).
  * **Prone (shared, `prone_apply prefix`):** BG3 house rules, on purpose (the user, 2026-11-24): ending concentration, no reactions, disadvantage on Strength and Dexterity saves and a fall ending its own turn all follow Baldur's Gate 3, not the tabletop rules, to match the BG3-style surfaces (Wet, Grease, fire). Do not "correct" them to the tabletop rules. Standing for half its movement is the tabletop rule. Every knock-down calls it; it ends concentration at once. A prone creature has no reactions (`combat_can_react`), disadvantage on Strength and Dexterity saves (`resolve_save`, "(disadvantage, Prone)"), and attacks against it have advantage from Engaged only ("(Advantage — Prone)"). It stands at the start of its turn and cannot Dash that turn (enemy `combat_grease_stood`, ally `cnt_a_stood`, player `combat_player_stood_round` hides Dash). Approach or Flee while restrained or pinned only strains. Leaving the reach of the player or an ally on its tile provokes an opportunity attack (`find_opportunity_attacker_against`).
* **Hex (RAW, 2026-11-20):** six hub options `Hex: <Ability>` (one HUD button, its fly-out wearing `ACTION_ICONS hex_<ability>`, or `reapply_hex_<ability>` while the curse waits to move) set `hex_ability` and go to `fight_cast_hex`. Besides +1d6 necrotic on hits, the target has disadvantage on ability checks with that ability (`hex_check_disadv`): a rolled check is rolled twice, the lower kept (breaking free of a restraint or web: Strength; keeping its feet on grease and the flight escape contest: Dexterity), and a fixed DC built from its score is a passive check and takes -5 (Shove's Strength and Dexterity defense, the Hide DC's passive Perception and the Intimidate DC: Wisdom). Saves are untouched (morale is a Wisdom save). Moving the curse after its target falls costs a bonus action, no slot, keeps concentration, and the ability is chosen again.
* **Slot spending:** `spend_spell_slot` spends a pact slot for anyone with Pact Magic (`pact_slots_max > 0`), so a spell's resolver need not ask the class.
* **Critical Hits (`crit_check`, `combat_dice.txt`):** A player attack roll that hits is a critical hit on a natural 20, or when the target is paralyzed and the player is Engaged with it. A saving-throw or area spell never crits. A crit rolls every die of the hit twice and adds the modifiers once: the weapon or spell dice (each Great Weapon Fighting die rerolled on its own) and every rider on the hit (Sneak Attack, Hex, Hunter's Mark, an item's extra packet, True Strike's and Booming Blade's on-hit dice, the Poisoner's Robes). Damage that comes later and not from the hit (Booming Blade's move damage, Ensnaring's thorns) is not doubled. `combat_player_crit` and `combat_crit_tag` (" (Critical)", shown in the damage banner) are set inside the hit's lock by `resolve_player_hit`, `resolve_player_weapon_hit` and, for attack-roll spells, `roll_spell_damage`; `combat_hit_nat20` carries the same value for Undead Fortitude. A new damage path that follows an attack roll calls `crit_check` and doubles its dice. Enemies and allies crit too: a natural 20 on their attack roll always hits and is a critical hit (a hit on a paralyzed target by an attacker Engaged with it as well), set inside the attack's lock (`combat_enemy_crit` / `combat_enemy_crit_tag` in `resolve_enemy_attack` and `resolve_enemy_attack_on_ally`, read by `roll_enemy_base_dmg` and the enemy's rider packet; `raa_crit` in `resolve_ally_attack`). A save attack never crits.
* **Damage Types, Defenses & Multi-Packet Math (`combat_dice.txt`):**
  * Every defender carries word-list strings `<prefix>resist_types`, `vulnerable_types`, `immune_types` (matched via `*script defense_flags`), plus `<prefix>nonmagic` (`"resist"`/`"immune"`) with `_silvered`/`_adamantine` bypasses (`combat_packet_is_weapon`, `combat_atk_magical`/`_silvered`/`_adamantine`, `defense_known`). Player defenses are persistent stats; Rage resists only `bludgeoning`, `piercing`, `slashing`.
  * `adjust_damage_packet` evaluates immunity (`0`), resistance (`floor(/2)`), and vulnerability (`*2`) in one pass (resistance + vulnerability cancel). Secondary damage uses separate `*_extra_dmg_*` packets; an enemy's comes from an `on_hit_rider` ability (`tools/ability_book.json`, e.g. `combat_enemy_ability_1_override "venom"`), never set by hand in a scene, and so does an on-hit stun (`stunning_blow`). `combat_incoming_dmg_suffix` and `combat_outgoing_dmg_suffix` stay separate so reactive retaliation never overwrites banner tags.
* **Player Spells, Enemy Spells & Data-Driven Casting:**
  * Choice labels follow `[b][ACTION][/b] [b][Name][/b] <prose>` (<=15 rendered words, checked by `tools/lint_choice_labels.js`; `battlehud.js` parses the cost tag and bold name). Sentences starting with epithets use `$!{var}` (`${var}` mid-sentence); narration labels end each fall-through branch with `*line_break`; `combat_attacker_name`/`_defender_name` are transient scratch—re-set after any intervening narration call.
  * **Booming Blade & True Strike:** Both are full Action weapon attacks (`booming_armed`, `fight_booming_trigger` fires on voluntary enemy moves; `true_strike_on` / `true_strike_radiant` uses INT/CHA and scales at 5/11/17).
  * **Repelling Blast:** `inv_repelling_blast` pushes Large-or-smaller hit foes 1 tier (`combat_shift_target_range`) without OAs.
  * **Dissonant Whispers / Deferred Banner Pattern:** Uses `combat_save_quiet true`, copies `check_last_banner` / `combat_roa_last_*` / `combat_boom_last_*` fields inside the cast lock, and prints after the lock so Reaction movement + reverse OA + Booming Blade print in order safely on refresh.
  * **Magic Missile & Leveled Modifiers:** `spell_damage_mod` adds to leveled spell damage (halved on save where applicable); Magic Missile adds flat `+1` per dart and allocates darts via `fight_target_magic_missile` (`combat_mm_darts_1..6`).
  * **Multi-Target Spells (shared):** a spell whose projectiles or targets the player shares out in the sidebar (`assignMultiTargetDart`, `combat_mm_darts_1..6` up to `combat_mm_darts_max`) arms the allocation in its hub option, sets the count with `projectiles_for_level <id> <level>` (the data's `projectiles`, plus `upcast.projectiles` per slot level above, or a cantrip's `cantrip_scale` tier), and goes to its `fight_target_<id>` entry label, which names it in `combat_mm_spell` for the one Cast/Cancel page, `fight_target_multi`. A spell that rolls an attack per projectile resolves through `fight_resolve_projectile_attacks <id>` (name and damage type from the data, every hit through `resolve_spell_hit`); its own resolver only spends the slot and prints the opening. Users: Magic Missile (its own resolver, no attack roll), Cause Fear at 2nd level, Scorching Ray, and Eldritch Blast from level 5 (2 beams, 3 at 11, 4 at 17; one beam below level 5 stays the single-target option). Agonizing Blast and Repelling Blast (`fight_repelling_blast`) apply to every beam that hits.
  * **Assigned Enemy Spells:** Defined per fight in `tools/encounter_catalog.json` (`"spells"`, max 3; cantrips omit `uses`) or via `combat_enemy*_cast_*_override` before `fight_library` (`compute_cast_dc`, `apply_enemy_spell_base`, `fight_pick_enemy_spell`). A caster with three leveled spells gets its at-will attack cantrip from `combat_enemy*_cantrip_override` instead, which takes no cast slot; `apply_enemy_spell_base` reads it before the slots, so the caster keeps its distance and casts the cantrip instead of closing with its own weapon. Non-player spells follow a three-layer architecture: (1) pure `spell_effect_<id>` in `combat_dice.txt`, (2) `flavor_npc_<id>` in `combat_prose.txt`, (3) `resolve_npc_cast_<id>` in `combat_spells.txt` + `spell_worth_casting` (`combat_ai.txt`) + turn dispatch (`combat.txt`).
  * **Enemy casting by spell shape:** an enemy's assigned spell is routed by its data, never by its id. Attack-roll, always-hits (Magic Missile, one packet) and save-for-damage spells go through `fight_enemy_cast_attack` (each ray its own page, "Another ray follows…"), save-or-condition spells through `resolve_npc_cast_condition` (a concentration spell starts the caster's concentration when it takes hold), Bane through `resolve_npc_cast_bane`, Grease through `resolve_npc_cast_grease`. An area spell then makes everyone else in its area save (`fight_enemy_cast_area`: `engaged` is the caster's position, `spot` the target's). The same shapes are cast at an ally (`fight_enemy_ally_attack`, `spell_worth_casting_at_ally`). An enemy's Thunderwave or Dissonant Whispers moves an ally away from the caster on the lane whichever foe it fights (`enemy_push_ally`). An action ability (the Net) is thrown at an ally too: `ability_target` names it for `ability_pick_action` / `ability_use_action` (its AC, third-person lines `flavor_ability_action_at_ally`). Riders (Ray of Frost Slows, Chill Touch stops the player regaining HP until the end of the caster's next turn (`combat_player_no_heal_slot`; heals print 0 "(Chilled)"), Shocking Grasp and Arms of Hadar spend the reaction and Shocking Grasp has advantage against a player in metal armour (brigandine, chain_jack, plate_harness), Thunderwave pushes; Dissonant Whispers moves the player a real step away from the caster on the lane (`combat_shift_all_ranges`), which provokes: the foe `find_opportunity_attacker` picks before the step swings on a page of its own after the caster's lines (`fight_enemy_cast_attack`); Vicious Mockery gives disadvantage) print through `combat_cantrip_rider`. A spell needs `npc_lines` and its `flavor_npc_<id>` lines. An enemy caster will not lay Web or Grease on a spot where any of its own side stands (`ai_own_side_at`). A ranged caster with a shorter-reach spell left edges in to that reach (`enemy_spell_want_tier`). A cornered caster weighs staying against retreating with each Engaged-range spell scored from its data (`combat_cornered_decide`, `ccd_spell_value`: an attack by its hit chance, a save by the player's chance to fail).
  * **Enemy buffs, heals and reactions:** `enemy_precast_buffs` (once per page, before initiative) puts up hour-long buffs: Mage Armor, False Life, Armor of Agathys (5 temp HP; `combat_enemyN_agathys`). Enemy temp HP soak in `adjust_damage_packet`. A melee hit (weapon, or a touch spell attack such as Shocking Grasp) on a warded enemy while its temp HP last deals its Agathys cold back to the attacker (`enemy_agathys_bite`, printed by `enemy_agathys_print`; `ally_agathys_bite`). `enemy_try_heal` heals the most hurt friend below half HP at its turn start; `enemy_try_blade_ward` wards when Engaged and below half HP. Shield (`enemy_shield_check`, a roll that would hit by under 5) and Absorb Elements (first elemental packet) are reactions, against the player's and allies' attacks.
  * **Ally casters:** ally slot 1 takes spells through `combat_ally_cast_spell_1_override` (and `_uses_`, `_chance_` 1-3, `combat_ally_cast_dc_override`); `apply_ally_roster` works out its DC and attack bonus. On its turn it casts a spell worth casting at its foe (`fight_pick_ally_cast_spell`, `spell_worth_casting_at_enemy`) in place of stepping and attacking: conditions through `resolve_npc_cast_condition`, damage through `resolve_ally_cast_damage` (rays, always-hits, saves, area, riders). Allies concentrate and carry a creature type (`combat_allyN_creature_type`). Grease goes through `resolve_npc_cast_grease`; Thunderwave throws the foe a step back (`ally_push_enemy`). A library type can carry its own spells: the `hedge_mage` ally (Hold Person, Shatter, Fire Bolt at will as 99 uses), its DC from its scores in `apply_ally_roster`.
  * **HUD Option Gates (`combat.txt` + `battlehud.js`):** Every spell option initializes `*temp combat_why_<id> "unowned"`, evaluates priority (`armor` > slot > `cannot_see` > spell-specific > `out_of_reach` > turn budget) via `combat_eval_spell_why`, gates `#` on `*if (combat_why_<id> = "")`, and registers in `battlehud.js` (`HUB_ORDER`, `SEED_SPELLS`, `REASON_TEXT`, `WHY_RANK`).
  * **In-Fight Replay Guard (`pageReplayGuard`):** In-fight spells write no replay locks; `web/scene.js` (`pageReplayGuard`/`pageReplayTrim`) + `combat_chain_begin`/`combat_chain_end` keep pages and multi-page chains deterministic (`PAGE_REPLAY_CLICK_KEYS = ["combat_player_chosen_target"]`). Out-of-combat/setup locks (`false_life_cast_locked`, `roll_locked`, `combat_init_locked`) remain.
  * **Data-Driven Spell Numbers (`tools/spell_book.json` → `node tools/gen_spells.js`):** Add combat metadata under `combat` in `spell_book.json`, regenerate `spell_facts_load`/`spell_range_lookup`/`spell_reach_flags`/`spell-reach.generated.js`, call the shared roll in `combat_spells.txt` (`roll_spell_damage "<id>" <is_area>` for a save or area spell, `resolve_spell_hit "<id>" <is_spell>` for an attack, `resolve_spell_heal`, `roll_spell_temp_hp`; all roll through `roll_spell_dice`), and verify with a seeded `"refresh": true, "refreshText": true` play script. Every spell's dice, type, save and upcast come from the data; no number is typed in scene code. A spell with several dice per hit passes the count through `combat_player_dmg_dice_count` (`resolve_spell_hit` sets it from the data, 1 for a one-die spell). A cantrip that grows with level reads `cantrip_scale`, and `spell_facts_load` works out the count for `character_level` (`spell_fact_hit_*`, `spell_fact_move_*`, `spell_fact_extra_*`, and a tier's `damage_dice`, which replaces `spell_fact_dice_count`: Fire Bolt, Ray of Frost, Chill Touch, Vicious Mockery, Poison Spray and Shocking Grasp roll 2 dice from level 5, 3 from 11, 4 from 17); a tier that changes the die size is refused by the generator. A heal spell names its upcast in `upcast.damage_dice` too, and `resolve_spell_heal` adds it per slot level above the spell's own (Cure Wounds +2d8, Healing Word +2d4; each has 1st and 2nd level options that set `combat_cast_at_level` and share one body, `fight_cast_cure_wounds` / `fight_cast_healing_word`). A spell paid from Pact Magic is cast at the pact slot's level (`pact_cast_level` sets `combat_cast_at_level`), so its data's `upcast` applies with no hub option: Arms of Hadar +1d6, Hellish Rebuke +1d10, Armor of Agathys +5 temporary hit points and +5 cold (`upcast.damage_flat`, kept in `agathys_dmg` at the cast). A spell that affects several creatures names how many in `targets` and the extra per slot level in `upcast.targets` (`spell_fact_targets`, `spell_fact_upcast_targets`; Bane: 3, +1). Absorb Elements is armed at a chosen level (`absorb_elements_level`); when it fires it spends that slot and sets the melee rider's dice count (`combat_player_extra_dmg_dice_count`, 1d6 +1d6 per level above 1st). Spells with their own shape keep their own code but read their numbers from `spell_facts_load`: Magic Missile and Scorching Ray (projectiles shared out in the target sidebar, count from `projectiles_for_level`), Hex, Hunter's Mark (its die is `favored_foe_die_sides`), Ensnaring Strike, Absorb Elements.

## 10. Dungeon Engine (`dungeon.txt`)

* **Core Flow & Encounters:**
  * `dungeon.txt` (`*gosub_scene`-only) provides `dg_run_begin` (resets per-run history, sets `wait_lock_reason`), `dg_run_end` (clears `dg_daylit`, `wait_lock_reason`), `dg_tide_check` (`time_period` Morning–Dusk = low water; Night/Pre-Dawn = high water), `dg_pick`, `dg_step` (`dg_step_locked`), `dg_harvest`, `dg_forage`, and `dg_spell_source`/`dg_spell_cast`.
  * **Encounter tables:** Set `dg_table` and `dg_call_id`, call `dg_pick`, read `dg_encounter` (`"none"` when exhausted). Each table label (`dg_table_<name>`) lists `*gosub dg_row "id" lowWeight highWeight` lines (rows in `dg_pick_1..16` get weight 0; `*rand` bounds clamp to >=2 for Quicktest). `dg_pick_locked` keys on `page_id` + `dg_call_id`.
  * **Movement & Refill:** `dg_step` advances 10 minutes, burns 1 light step, and rolls 40% for encounters on hallways/forks (`dg_dest_hall true`, never twice in a row, skipped on chalked nodes or plain bends). `dg_done_<node>` and room action flags (`dg_<prefix>_r<N>_*`) persist across runs and clear only in `dg_respawn` (called by `dg_run_begin` once `dg_respawn_days` = 3 days have passed since `dg_reset_day_<dungeon>`). Map seen/chalk flags persist permanently. Read `dg_from` inside the step lock before `dg_step` overwrites it.
* **Light, Darkness & Spells:**
  * `dg_light_prompt` offers a torch (6 steps, +3 once via Control Flames `dg_torch_fed`) or hooded lantern + oil (24 steps) or walking in the dark. `dg_daylit` makes open-air dungeons lit by day/dusk and dark at night/pre-dawn/weather severity >=3 (`dg_fell_dark` flags dusk-to-dark transitions). Rooms with a light source set `dg_lit_here` (cleared by `dg_step`/`dg_run_begin`).
  * `dice_engine` calls `dungeon.txt dg_dark_check` directly for darkness disadvantage; `dg_fight_prep` sets `combat_enemy_advantage` in the dark. `refresh_invocations` recomputes `sees_in_dark` from worn rings (`equipped_ring1_id`/`_ring2_id`) before darkness checks.
  * **Shared Spell Gate (`dg_spell_source` / `dg_spell_cast`):** Takes `<spell_id> <name> <mins> <kind>` (`cantrip`, `ritual`, `spell`) and sets `dg_ss_can`, `dg_ss_cost` (`free`/`ritual`/`slot`/`scroll`), `dg_ss_why`, `dg_ss_tag`, checking racial knacks, invocations, Wizard rituals, class slots, and fallback scrolls (`scroll_<id>`). `dg_swa_check`/`dg_dm_check` remain wrappers.
* **Harvesting & Foraging:**
  * `dg_harvest` (Survival, 15m, `dg_hv_creature`, `dg_harvest_info`) yields 1 ingredient (2 at DC+5); venomous failures nick 1 HP (`stat_bump_locked`).
  * `dg_forage` (better of Nature/Survival, 15m, `dg_fg_plant`, `dg_forage_info`, optional `dg_fg_stock` cap variable) yields 1–2 plant pieces and spoils the patch until refill.
* **Dungeon Map Panel (`dungeonmap.js`, `dungeons/<dungeon>.js`):**
  * **Scene Rules:** Every node is `<prefix>_<id>` (`silt_j1`, `lsf_r4`) with matching `dg_seen_<node>` and `dg_mark_<node>` (`none` pair exists for Quicktest). Keep internal codes (`j1`, `r2`) out of player-facing headings.
  * Move options must start with `"Go "` + direction word (grid cardinal or off-grid 8-point compass word matching `dungeonmap.js compassWord`); room actions must not start with `"Go up/down/back out"`. Hidden edges use `[from, to, "<flag>"]`.
  * Three modes: map-only (`body.dgMapOnly`) when only moves/chalk/exits exist, classic list with bar when room actions exist, or user-toggled Classic/Map. `roomFit` wraps multi-word room names dynamically. `check_dungeon_map.js` validates scenes against `dungeons/*.js` and requires a single dispatch entry per dungeon in `dg_run_table`, `dg_respawn`, and `dg_forget_map`.
  * Node intros write both a `lit` and a `dark` description, then call `dg_env` (tide + 8-item rotating ambient) or `lsf_env` / `lsf_env_quiet` (forest sky + rotating ambient).

## 11. Balance Data

* **Fight Log (`fightlog.js`):** Passively records up to 500 fights to `localStorage` (`mp_fightlog`, exported via `fightlog_export_req`). Never writes game state.
* **Opening Formation & Initiative:** Inside `fight_setup` (before lane seeding) and `combat_roll_initiative`: (1) the player acts first unless `combat_enemy_advantage` is set; (2) any enemy starting at range 0 is stepped to range `1` (Close) unless `combat_enemy_advantage` or `combat_opens_engaged` is set. Keep at least one frontline enemy reachable on turn 1 in standard fights.
* **Shared Lane Terrain & Battlefield Strip:**
  * Scenes may enable `combat_terrain1..3` (`type`, `position`, `capacity`, `blocks_los`; slot 4 exists so a spell's patch always has room, and every reader loops to `combat_terrain_slot_cap`) or set `combat_terrain_layout` (`fixed`, `random_light`, `random_standard`, `hybrid`; previewed via `combat_terrain_layout_preview`):
    * **Chokepoint (capacity 1):** An adjacent melee/reach ally blocks crossing unless the player spends movement to **Trade Places** or **Call Back**.
    * **High Ground:** `+2` to ranged weapon/spell attacks against lower targets; `-2` against elevated targets.
    * **Cover:** `+2 AC` against ranged weapon/spell attacks.
    * **Difficult Terrain:** Any step entering, leaving, or starting on it consumes all remaining movement for the turn (blocking Dash's extra step).
    * **Web (laid by the spell, never by a scene):** placed in the first open slot at the target's lane position and cleared when the caster's concentration ends. It is difficult terrain for everyone. Each living enemy on it makes a Dexterity save when it lands, when it starts its turn there, and when it ends a turn there after moving in (`web_catch`); a failure is Restrained with source `combat_player_web`. Every behavior profile scores a webbed spot 3 below its neighbours (`combat_score_terrain_destination`), on top of the difficult-terrain cost.
  * `resolve_behavior_profile` assigns terrain weights scored by `combat_score_terrain_destination` and stepped by `combat_choose_terrain_step` (strictly better adjacent coordinate, obeying capacity/reach).
  * `combat_range_mode` defaults to `legacy4` (0–3); set `expanded6` before `fight_library` for 6-band fights (`Engaged`, `Close`, `Near`, `Mid-Range`, `Far`, `Long Range`; lane cap 8 via `combat_max_range`).
  * `#statSidebar` renders the Battlefield Strip (`paintNodeCard`, `TERRAIN_RULES`, target/Magic-Missile dart click selection).

## 12. Overworld Travel, Camping & Inns

* **Overworld Data (`web/mygame/overworld-data.js`, `overworld.txt`):**
  * `window.Overworld` defines all tiles (`kind`, `also`, `territory` in `TERRITORIES` with `patrol` danger shift, `danger` 0–3, `climate`, `water`, `hereNight`/`hereStorm`), road edges (`EDGES` with `[from, to, miles, terrain]`), and drawn map `FEATURES` (e.g., `coldspine.svg` via `node tools/gen_overworld_art.js`).
  * `kind: "woodroad"` counts as both `road` and `forest` (`kindIn`) for travel events. `route(from, to)` runs Dijkstra on travel *time* (`MINUTES_PER_MILE = 24` min/mile on foot × terrain `pace`: `road` 100%, `overland` 200%, `blocked` impassable; mounted riders move at 12/15/24 min/mile by day/dusk/dark).
  * `overworld.txt` validates `ow_dest` against `Overworld`, plans routes/events once under `ow_trip_locked`, walks leg by leg inside the lock (`calc_exposure`, `weatherSync`, `load_extra_mins`, `advance_time` once per leg), and updates `ow_pos` on the next page.
* **Camping & Inns (`overworld/camp.txt`, `ow_camp`):**
  * Non-settlement tiles (`ow_can_camp`) open `camp_hub` (Sleep until dawn/8h, Short rest, Training sharing `last_training_day`—refused at dusk/night/severity >=3, Break camp). `ow_on` stays true so rations and exposure run.
  * `ow_camp` (`ow_camp_locked`) calls `resolve_sleep` as a shared bunk (`exposure_camping` active; camp fire, Control Flames, camp kit, and oilcloth cut cold/wet exposure).
  * Inn room keys set `*_room_until` (`campaign_day * 1440 + clock + 1440`) for 24-hour access and call `resolve_sleep`.
* **Mounts (`horse_dealer.txt`, `has_horse`):**
  * Buying a horse (`has_horse`) halves day/dusk/dark travel pace on the overworld without increasing personal pack capacity. `horse_upkeep` (in `calendar.txt`'s daily rollover when `ow_on` is false and no escort is active) bills 2c/night in town/city or 1c/night in village (`horse_owed`, `horse_unpaid_days`; after 3 unpaid days the stable keeps the horse).
* **Road & Camp Events (`TRAVEL_EVENTS`, `CAMP_EVENTS` in `overworld-data.js`, `overworld/travel_events.txt`):**
  * `Overworld.travelEventPlan` / `campEventPlan` deterministically schedule at most one event every `TRAVEL_COOLDOWN_DAYS` using `ow_event_seed` (never on towns; supports `when` light filter, `ford` ground-state check, `ow_camp_fire_shared`, `ow_event_force` for tests, and tile-matched `te_night_beasts`). Events resolve to `ow_event_done` or `ow_camp`.
* **Caravan Escorts (`CARAVAN_YARDS`, `CARAVAN_LINES`, `hall_escort.txt`, `port_valen/radiant/caravan_lot.txt`):**
  * Yards and scheduled weekly lines live in `overworld-data.js` (`es_set_line` populates `es_ctx_*`; checked by `node tools/check_escort_lines.js` against `tools/escort_snapshots.json`).
  * **To add a town:** Add a `CARAVAN_YARDS` entry (place `"glot"` for shared `caravan_lot.txt`) and `CARAVAN_LINES` entries in `overworld-data.js`; add a hub stub label calling `es_set_line` + `*goto_scene port_valen/radiant/caravan_lot cl_main`, one branch in `caravan_lot.txt cl_leave`, return/arrival entries in `hall_escort.txt` (`es_back` and `es_pay`), tile `departVia`/`arriveVia`/`walkVia` fields if needed, and update `rj_escort_gov` credit.
* **Courier System & Contractor's Insignia (`hall_courier.txt`, `inventory-data.js` `Insignia`):**
  * `Overworld.courierPostings(origin, day, count)` generates deterministic board postings (`crp1..3_*`, `cr_taken_log`, `COURIER_TILES`) into `crs1..3_*` satchel slots (`cr0` placeholders for Quicktest). `notice_board.txt nb_read` and `hall_courier.txt cr_back` serve all town notice boards and `overworld.txt ow_here` renders `Deliver ...` options dynamically.
  * `Insignia` (`inventory-data.js`) manages separate per-government pages in `PAGES` (`scales`, `gault`), ladders, `register`/`credit`/`issue`/`canTake`/`needText`/`line`/`courierDelivered`. Scenes never branch on government ids directly (`node tools/check_insignia.js`).
* **Weather Zones (`WEATHER_ZONES`, `DISTRICT_ZONE`, `WEATHER_PROFILES`):**
  * Each territory/tile/district resolves to a weather zone (`reach`, `vale`). `Overworld.weatherSync` parks inactive zones in `wx_slots` (JSON) so scenes always read standard globals (`weather`, `weather_tomorrow`, `rain_streak`, `dry_streak`). Daily rollover updates visited zones only (`weatherRollBegin`/`weatherRollNext`); unvisited zones roll fresh on first entry (`wx_fresh_roll`).
* **Deterministic NPC Names (`names.txt` `name_make`, `names-data.js`):**
  * Uses `name_race`, `name_gender`, `name_region`, `name_seed` -> `name_first`, `name_last`, `name_full`, `name_look`. Use `RACE_WEIGHTS` presets for varied crowds and list fixed story NPCs in `RESERVED`.

## 13. Calendar, Weather, Exposure & Persistent Healing (`calendar.txt`)

* **The Neglect Clock (Hunger/Fatigue) Is Engine-Global, Not File-Local:** `minutes_since_meal`, `minutes_since_rest`, `neglect_damage_hunger`, and `neglect_damage_fatigue` are global stats computed in `calendar.txt` `advance_time`. Any scene calling `*gosub_scene calendar advance_time` advances them consistently across file boundaries and must repeat the 3-line neglect-death check if `hp_current` can hit 0.
* **Two `*gosub_scene calendar advance_time` Calls on One Page Will Double-Advance on Refresh:** Because `time_advance_locked` / `locked_time_advance_page_id` / `locked_time_advance_id` track only the last call on a page, always put a `*page_break` or `*choice` between two `advance_time` calls.
* **Persistent Wounds & Slow Healing:** After the prologue, `hp_current` persists across rest. `recalc_hp_from_neglect` applies hunger/fatigue penalties via delta (`hp_debt_applied`) so eating or sleeping refunds only that debt. `resolve_sleep` heals 1 HP per calendar day (2 in a private room, via `last_sleep_heal_day` / `sleep_heal`), plus +1 each while wounded for `has_camp_kit` (on shared bunks/camps) and `dressing_on` (consumed), up to 3 HP max. Out of combat, mundane healers and healing consumables share the daily `last_mundane_treatment_day` limit; in combat, potions are unlimited. Never set `hp_current` to `hp_max` post-prologue (`tools/lint_slow_healing.js`).
* **Port Valen District Travel (`current_district`, `get_district_distance`, `port_valen_travel_to`):** `current_district` tracks location across hubs; `get_district_distance` stores each district's distance from the compound (Harbor 15m, Civic Heights 35m, Patrician Quarter 40m, Dredge-End 60m), and `port_valen_travel_to` charges the sum of both ends.
* **Derived Calendar, Weather & Memory (`day_of_week`, `weather`, `ground_state`):**
  * `day_of_week` (`(campaign_day - 1) modulo 7`: Ironday through Hallowday) is derived on every call (never write weekday names in prose).
  * `weather` rolls once per calendar day inside `advance_time`'s `days_to_pass > 0` block via `roll_weather` and `fix_weather_season` (~55% persistence, stepping extremes down and converting out-of-season types).
  * `weather_tomorrow` rolls a day ahead (~80% accurate; `forecast_missed` flags misses), exposing `tomorrow_severity` (0–3) and `forecast_str`.
  * `rain_streak` and `dry_streak` derive `ground_state` (`"dry"`, `"wet"`, `"sodden"` on 3+ wet days) for sky-layer ground-residue prose (`tools/lint_weather_names.js`).
* **Temperature & Outdoor Exposure (`temp_index`, `calc_exposure`):** `temp_index` (0–5, `temperature_band`) derives from season, hour, weather, and `climate_shift` (+20% per step beyond bounds via `temp_extreme`). Before outdoor `advance_time`, set `exposure_base_mins` and call `*gosub_scene calendar calc_exposure`; cold/wet/heat penalties (max +100%) add only to meal and rest clocks, reduced by `garment_traits` (90% max per part) and oilcloth/camp kit/fire.
* **Derived Weather Flags (`update_weather_flags`):** Called from `update_hub_condition`, setting `weather_severity` (0–3), `weather_visibility` (`"clear"`, `"reduced"`, `"poor"`), `weather_wet`, `weather_cold`, and `street_life` (`"normal"`, `"thin"`, `"empty"`). Gate closures and crowds on these flags, using raw `weather` names only in the sky layer's weather sentence (`cut_*_closed`, `tools/render_hub.js`).
* **Weather & Prep Check Idioms:** Gate weather disadvantages on derived hazard booleans (`(weather_wet) or (weather_cold)` for footing, `(weather_visibility = "poor") or (weather = "Snow")` for sight) right before `roll_d20_check` when scene prose branches on weather. `prep_*` flags grant `advantage`, while failed journey beats set a one-beat `disadvantage` flag instead of inventing scene-local HP damage helpers.
